Shortcuts & menus

  • Toolbar / page / tab context menu: clear, clear + reload
  • Page / tab context menu: add site to allowlist

Rebind shortcuts in about:addons → gear → Manage Extension Shortcuts.

Firefox notes

  • HTTP cache clearing via browsingData is always global; hostname filters do not limit it.
  • Cache Storage (Cache API) has no browsingData key on Firefox — this extension injects a page script on matching open tabs.
  • Manifest V3 uses a background event page (background.scripts), not an extension service worker.
  • Desktop: Firefox 140+. Android: Firefox 142+ when the add-on is available for that channel.
